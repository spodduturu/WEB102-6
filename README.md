# Web Development Project 6 - *SpaceX Dashboard*

Submitted by: **Saakshi**

This web app: A dynamic and interactive dashboard that visualizes SpaceX launch data. It allows users to search, filter, and explore launch missions by name, year, and success status. The app includes detailed views for each launch, summary statistics, and two customizable charts. Users can also toggle between visualizations for a more insightful experience. Built using React, React Router, and Recharts, this project highlights real-world data storytelling in a clean and responsive UI.

Time spent: **6** hours spent in total
